# CodeForge API

CodeForge API is the backend for a mobile app in active development for learning software architecture and code at your own pace. The project is public and open source: anyone can clone it and keep building on it. API messages are in Portuguese. The source code is in English.

The API is built with Java 21, Spring Boot 4.1, Gradle, Spring Web, Spring Security, and Validation. PostgreSQL, Spring Data JPA, and Flyway are on the classpath for the persistence adapter that comes next. The database is not connected yet. Code is organized with hexagonal architecture, one package per feature. `domain` holds the business concepts. `application` holds use cases and the ports they call. `adapter/in` receives HTTP and the bearer token. `adapter/out` talks to the outside world. Today that outside world is memory, not Postgres. The `account` feature signs a person in and returns the authenticated account. `POST /api/auth/login` accepts the development user `alex@codeforge.dev` / `Codeforge1` and returns `{ "accessToken": "mock-token" }`. `GET /api/account` reads `Authorization: Bearer mock-token` and returns the name, greeting, level, streak, and daily goal. Tracks, the daily challenge, real JWT, and registration come later, behind the same ports.
